================================================================================
ENVIRONMENT.YML REORGANIZATION - OPTION 4: BY ROLE/WORKFLOW
================================================================================

This structure groups libraries by how users work with them, making it intuitive
to enable/disable entire workflows and understand dependencies.

================================================================================
GROUP 1: DATA PREPARATION (Core Data Wrangling)
================================================================================
Purpose: Load, clean, transform, and explore data
- pandas              # Tabular data manipulation
- polars              # Fast DataFrame operations

- scipy               # Scientific computing

================================================================================
USAGE NOTES
================================================================================

1. ENABLING/DISABLING WORKFLOWS
   - You can comment out entire groups if not needed
   - For example, comment out GROUP 9 (Dashboards) if you don't need Streamlit/Dash
   - Comment out GROUP 10 (RAPIDS) if you don't use GPU-accelerated data science

2. DEPENDENCY RELATIONSHIPS
   - GROUP 4 (Training & Scaling) depends on GROUP 2 (Model Building)
   - GROUP 5 (Monitoring) works with any GROUP 2-4 tools
   - GROUP 6 (Visualization) is independent of other groups
   - GROUP 10 (RAPIDS) enhances GROUP 1 (Data Preparation) with GPU support

3. OPTIONAL PACKAGES
   - Language servers (texlab, r-languageserver) are optional
   - RAPIDS (GROUP 10) requires NVIDIA GPU but is optional
   - Graphistry is optional for network visualization
   - Streamlit & Dash can be used interchangeably

4. RESOURCE CONSIDERATIONS
   - Full installation: ~15-20 GB
   - Minimal (GROUP 1-3 only): ~5-8 GB
   - Development (GROUP 1-3, 7): ~8-12 GB
   - Production (GROUP 1-6): ~15 GB
